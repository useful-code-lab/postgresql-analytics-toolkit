# PostgreSQL Analytics Toolkit

Практический набор SQL-паттернов для **PostgreSQL**, который помогает изучать, создавать и оптимизировать аналитические запросы на данных, приближенных к реальным бизнес-задачам.

Проект можно использовать как **учебную базу, шпаргалку по SQL, источник готовых решений или основу для собственных аналитических проектов**.

## 🎯 Что вы получите от проекта

Этот репозиторий поможет вам не просто посмотреть примеры SQL-кода, а разобраться, **как PostgreSQL используется для решения практических задач аналитики**.

С помощью проекта вы сможете:

* изучить структуру полноценной реляционной базы данных;
* потренироваться писать SQL-запросы на связанных таблицах;
* понять, как индексы влияют на работу запросов;
* создавать аналитические отчёты непосредственно в PostgreSQL;
* использовать оконные функции для анализа данных;
* применять CTE для построения сложных запросов;
* работать с JSONB и полуструктурированными данными;
* рассчитывать Retention и другие бизнес-метрики;
* выполнять ABC-анализ товаров;
* использовать готовые SQL-паттерны как основу для собственных задач.

Проект особенно полезен тем, кто хочет перейти от изучения отдельных SQL-команд к **решению задач, которые встречаются в реальной аналитической работе**.

## 📚 Что внутри

Проект построен как последовательный набор SQL-файлов:

```text
01_schema.sql
02_seeds.sql
03_indexes.sql
04_analytics.sql
05_pro_queries.sql
```

### `01_schema.sql` — структура базы данных

Создаёт основу проекта:

* таблицы;
* первичные и внешние ключи;
* связи между сущностями;
* ограничения `Constraints`;
* структуру данных для дальнейшей аналитики.

**Польза:** можно увидеть, как организовать данные так, чтобы на них было удобно строить аналитические запросы.

---

### `02_seeds.sql` — демонстрационные данные

Заполняет базу тестовыми данными.

**Польза:** не нужно самостоятельно придумывать данные для экспериментов — можно сразу развернуть БД и начать выполнять запросы.

---

### `03_indexes.sql` — оптимизация запросов

Содержит индексы, предназначенные для ускорения работы с данными и связанных запросов.

**Польза:** можно на практике разобраться, зачем нужны индексы и какие поля имеет смысл индексировать при работе с аналитическими данными.

---

### `04_analytics.sql` — базовая аналитика

Содержит запросы для получения операционной и бизнес-отчётности.

**Польза:** это отправная точка для понимания того, как обычные данные превращаются в показатели, необходимые для анализа бизнеса.

---

### `05_pro_queries.sql` — продвинутые SQL-паттерны

Здесь собраны более сложные сценарии:

* оконные функции;
* `CTE`;
* `JSONB`;
* агрегации;
* сложные фильтрации;
* аналитические расчёты.

**Польза:** можно изучать конструкции, которые часто используются при построении сложной аналитики непосредственно на уровне PostgreSQL.

# 📊 Практические задачи

## Retention Analysis

Расчёт удержания клиентов по периодам.

Запрос позволяет определить, какая доля пользователей возвращается и совершает покупки в последующие периоды.

Используются временные интервалы и `Self JOIN`.

**Что можно получить:** практический шаблон для анализа повторных покупок и поведения клиентской базы.

---

## ABC-анализ товаров

Классификация товаров по их вкладу в общую выручку.

Товары распределяются по группам:

* **A** — наиболее значимый вклад в выручку;
* **B** — средний вклад;
* **C** — небольшой вклад.

Расчёт выполняется с использованием оконных функций и кумулятивной доли.

**Что можно получить:** готовый паттерн для анализа ассортимента и определения наиболее значимых позиций.

---

## JSONB и работа с документными данными

Проект показывает, как использовать возможности `JSONB` в PostgreSQL.

В примерах рассматриваются:

* формирование JSON-структур;
* агрегация данных в JSON;
* фильтрация данных;
* работа с полуструктурированной информацией.

**Что можно получить:** практическое понимание того, как сочетать классическую реляционную модель PostgreSQL с JSON-данными.

# 🚀 Как использовать проект

### 1. Создайте базу данных PostgreSQL

Например:

```bash
createdb analytics_db
```

### 2. Выполните SQL-файлы последовательно

```bash
psql -U user -d analytics_db -f 01_schema.sql
psql -U user -d analytics_db -f 02_seeds.sql
psql -U user -d analytics_db -f 03_indexes.sql
psql -U user -d analytics_db -f 04_analytics.sql
psql -U user -d analytics_db -f 05_pro_queries.sql
```

### 3. Изучайте запросы и экспериментируйте

Изменяйте условия, добавляйте собственные запросы и проверяйте, как меняются результаты.
